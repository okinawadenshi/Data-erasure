# 情報資産を、知識で守る。｜データ消去とPC買取のワンストップソリューション（提案書LP）

株式会社沖縄電子（PCハードウェアプロショップ、1972年創業）が、機密情報・個人情報を扱う企業・団体様に向けて提供する「データ消去・PC買取・リユース」のワンストップソリューションを紹介する、1枚構成の提案書（プロポーザル）ランディングページです（CO₂削減レポートはご要望に応じて発行するオプションサービスです）。沖縄県内企業で唯一、自社オンサイトでのデータ消去・物理破壊に対応しています。

添付のPowerPoint提案書（「情報資産を、知識で守る。」Proposal 2026）の内容を基に、既存サイト [o-kaitori.jp](https://o-kaitori.jp/)（株式会社沖縄電子 法人向けPC買取サイト）のブランドトーン・実績情報を参照して1ページに再構成しました。

## ページ構成（index.html 1枚）
1. ヘッダー：ロゴ、ページ内ナビ、無料相談フォームへの金色CTAバッジ
2. ヒーロー（#hero）：メインメッセージ「情報資産を、知識で守る。」、対応サービスタグ（DATA ERASURE / ON-SITE / PC BUYBACK / REUSE / CO2 REPORT〈任意〉）、「沖縄県内企業で唯一、自社オンサイトでのデータ消去・物理破壊に対応」の訴求、パルスアニメーション付き金色メインCTA
3. お悩み（#issues）：倉庫に眠るPC／説明責任の不安／コストの増大／持ち出しリスクの4課題＋セクション末尾CTAバナー
4. 注意点（#risk）：「廃棄業者に渡したから安心」ではないことを図解・リスクカードで提示
5. 事例（#case）：浦添市役所PC83台盗難事件の統計データと公式発表引用、沖縄電子による防止策＋セクション末尾CTAバナー
6. 設備（#equipment）：実際に利用しているデータ消去機「JetEraser HDE-GT400/GT600」、物理破壊機「ストレージパンチャー STPN-30」の図解・スペック紹介、オンサイト対応の訴求＋セクション末尾CTAバナー
7. 解決策（#solution）：データ消去／オンサイト対応／PC買取／リユース・リサイクル／CO2レポート（オプション扱いを明記）の5サービス
8. 選ばれる理由（#trust）：1972年創業、年間12,000台以上の買取実績、1度6,000台の受入実績、沖縄県内企業で唯一の自社オンサイト対応
9. 流れ（#flow）：お問い合わせ〜証明書発行までの5ステップ（CO2削減レポートはご要望に応じて発行するオプションとして明記）
